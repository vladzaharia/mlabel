## Configure it

Set `delimiter` independently for input and output. This example also chooses Windows-style line endings for output.

Delimiter settings change the file format, not the form. The downloaded sample begins with `id;comment`; MLabel still shows those as two separate fields.

The relevant setting is in `input.adapterConfig` and `output.adapterConfig`. The download above includes the surrounding configuration.

```jsonc
{
  "input": {
    "adapterConfig": {
      "delimiter": ";",
    },
  },
  "output": {
    "adapterConfig": {
      "delimiter": ";",
      "newline": "\r\n",
    },
  },
}
```

## Try it and check the result

Choose Pass and export. The output should contain:

```text
id;verdict
r001;pass
```

A remaining file preserves the input’s detected dialect. Changing the output delimiter does not convert remaining records to that delimiter.

If your file is shown as one large column, check that its actual separator matches `input.adapterConfig.delimiter`. [More CSV settings →](/config/adapters/)
