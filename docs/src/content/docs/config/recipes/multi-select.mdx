## Configure it

Put an **array of enum choices** in `output.fields`. Each choice becomes a checkbox. Set `required: false` when an empty selection is a valid “no issues” answer.

The example includes **D**, **P**, and **M** shortcuts. They toggle a choice on or off. A labeler can also click each checkbox.

The relevant setting is in `output.fields.1`. The download above includes the surrounding configuration.

```jsonc
{
  "name": "issues",
  "type": "array",
  "display": "Problems present",
  "required": false,
  "items": {
    "type": "enum",
    "choices": [
      {
        "name": "delivery",
        "display": "Late delivery",
        "shortcut": "d",
      },
      {
        "name": "packaging",
        "display": "Damaged packaging",
        "shortcut": "p",
      },
      {
        "name": "contents",
        "display": "Missing contents",
        "shortcut": "m",
      },
    ],
  },
}
```

## Try it and check the result

Select Damaged packaging, then Late delivery, and export with **Save**. The `issues` cell contains `["delivery","packaging"]`: configured order, even if the labeler clicked in a different order. CSV adds quotation marks around the JSON array.

Try again with no boxes selected. Because the field is optional, the record can still be exported. A required multi-select needs at least one selection; use a separate explicit “None” decision if your project needs proof that someone reviewed every record.
