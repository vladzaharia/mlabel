## Configure it

Declare `sourceId` as an output field and set `fill.from` to the input name `id`. The input and output types must match.

A copied field produces **no answer control**. The labeler sees the ID in the source card and answers the separate review question. To copy the same ID into another column, add another text output field with the same `fill.from`.

The relevant setting is in `output.fields.0`. The download above includes the surrounding configuration.

```jsonc
{
  "name": "sourceId",
  "type": "text",
  "fill": {
    "kind": "copy",
    "from": "id",
  },
}
```

## Try it and check the result

Select Pass and export. The resulting CSV is:

```csv
sourceId,verdict
r001,pass
```

The source column is still named `id`. `display` only changes on-screen captions; use the output field’s `name` to change an exported header.
