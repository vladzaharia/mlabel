You need the MLabel app, a project configuration, a data file, and your project's labeling
instructions. Your administrator or preparer should provide the last three. You do not need
to write a configuration or use a terminal.

## Start your assignment

1. [Install MLabel](/start/download/) if it is not already installed.
2. Open the configuration supplied for your assignment. MLabel may load it automatically.
3. Open your assigned data file and answer any questions about the labeling session.
4. Read each record, enter your answers, and move to the next record.
5. Select **Save** to export, then return the resulting files to your preparer.

## Before switching files

MLabel keeps **one saved session at a time**. To pause, close the app and later reopen the
same configuration and input file at the same paths. To hand work over, export it first.
Partially entered labels do not travel in the remaining file.

If you cannot judge a record, follow your project's instructions. Use an "Unclear" option
only if the project provides one; otherwise leave the required answer empty and ask your
project contact. Do not guess just to make the progress count increase.
