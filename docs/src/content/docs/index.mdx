## What it is

MLabel ingests tabular data, shows you one record at a time, and exports labeled data
matching a configured output schema. It runs entirely on your machine: nothing you load
or label ever leaves it.

<CardGrid stagger>
  <Card title="Nothing is hard-coded" icon="setting">
    Fields, types, widgets, layout, validation and keyboard shortcuts all come from your config.
    Adding a column means editing one file, not shipping a build.
  </Card>
  <Card title="Local by construction" icon="approve-check">
    The only remote request MLabel can make is its update check, and a single config key switches
    even that off. Everything else is denied at the network layer.
  </Card>
  <Card title="Nothing is lost" icon="document">
    Finished records go to `*-output`; anything unfinished is re-emitted to `*-remaining`, ready to
    load straight back in.
  </Card>
  <Card title="Built for teams" icon="puzzle">
    Split a file across labelers, then join their finished work back together — with schema
    validation and duplicate detection on the way in.
  </Card>
</CardGrid>
