MLabel helps you read one record at a time, enter your judgment, and save the results as a
file. Your data and labels stay on your computer. A project configuration determines what
you see and which questions you answer.

## How the files fit together

| File                             | What it is for                                              | Who supplies it                        |
| -------------------------------- | ----------------------------------------------------------- | -------------------------------------- |
| Project configuration (`.jsonc`) | Defines the source columns, questions, and exported columns | Administrator                          |
| Input data (`.csv`)              | The records to label                                        | Preparer                               |
| `*-output.csv`                   | Finished records and their labels                           | MLabel, when you select Save           |
| `*-remaining.csv`                | Unfinished source records, ready for another pass           | MLabel, when unfinished records remain |

A saved session is separate from these files. It lets you resume unfinished answers on the
same computer; a remaining file contains the source records, **not partially entered labels**.
See [saving and resuming](/guide/sessions/).
