Download from the [MLabel releases page](https://github.com/vladzaharia/mlabel/releases/latest). If your project requires a specific version, use the release or installer your administrator supplies.

## Which build

| Your computer                         | Download                                 | Next step                                                    |
| ------------------------------------- | ---------------------------------------- | ------------------------------------------------------------ |
| Mac with Apple Silicon                | `.dmg` with `arm64` in its name          | [Install on macOS](/start/install-macos/)                    |
| Mac with an Intel processor           | `.dmg` with `x64` in its name            | [Install on macOS](/start/install-macos/)                    |
| Windows                               | The Setup `.exe` matching your processor | [Install on Windows](/start/install-windows/)                |
| Windows, when you need a portable app | The `.exe` with `portable` in its name   | [Portable setup](/start/install-windows/#the-portable-build) |

On a Mac, **Apple menu → About This Mac** shows the chip or processor. On Windows, **Settings → System → About** shows the system type. Choose from the architectures offered by the release.

You can ignore `.blockmap`, `.yml`, and macOS `.zip` files when installing by hand; they support the update process. The normal Mac download is the `.dmg`.

## Verifying what you downloaded

The macOS release is signed and notarized. Windows builds are unsigned and may show SmartScreen. A warning is not enough to determine whether a file is safe or unsafe: confirm that it came from the official release or your administrator, then follow the platform-specific install guide and your organization's policy.
