This walks through one assignment from opening the project to returning your work. Have
MLabel [installed](/start/download/), the configuration and CSV your preparer supplied,
and your project’s labeling instructions. You do not need to edit the configuration.

<Steps>

1. ### Open the project configuration

   Drop your `.jsonc` on the window, or click **Select config**. If MLabel found a config
   next to its executable or remembered your last one, this step is already done.

   <Shot
     name="start-need-config"
     alt="The config screen with a large drop zone and a Select config button."
   />

2. ### Open the assigned data file

   Now MLabel asks for a data file. Drop a `.csv` on the window or pick one.

   <Shot name="start-need-input" alt="The data screen, prompting for a CSV file to label." />

   The file must have the columns your config's `input.fields` declares. Extra columns are
   ignored with a warning; a **missing** column is an error and the file is refused —
   nothing is loaded, so a mismatched file can never be exported over.

3. ### Answer the setup questions, if there are any

   If the config declares any [session fields](/config/fill/#session), you are asked them
   once, up front. The answers are written onto every completed output row — think "who is
   labeling" or "which guideline version".

   Configs with no session fields skip this screen entirely.

4. ### Label

   <Shot
     name="tutorial-labeling"
     alt="The labeling view: input cards on the left showing the record, an output form on the right."
   />

   The record is on one side, the form on the other. Fill it in, then move on:

   | Key                             | Action                |
   | ------------------------------- | --------------------- |
   | <kbd>→</kbd> / <kbd>Enter</kbd> | Next record           |
   | <kbd>←</kbd>                    | Previous record       |
   | <kbd>1</kbd>–<kbd>9</kbd>       | Pick the *n*th choice |
   | <kbd>?</kbd>                    | Show every shortcut   |

   Progress at the top shows how many records are complete. A record counts as
   complete when every required field holds a valid value — see
   [Labeling](/guide/labeling/).

   Your work is saved continuously. Closing the app and reopening it offers to
   [resume](/guide/sessions/).

5. ### Export your work

   Press **Save** (or <kbd>⌘/Ctrl</kbd>+<kbd>Enter</kbd>) whenever you like — you do not
   have to finish everything first.

   <Shot
     name="tutorial-done"
     alt="The completion screen showing counts of exported and remaining records, with buttons to reveal each file."
   />

   MLabel writes the results next to your input:

   - `yourfile-output.csv` — every complete record, in the output schema.
   - `yourfile-remaining.csv` — everything unfinished, in the _input_ schema.

   **Show in Finder** (macOS) or **Show in File Explorer** (Windows) locates a file in your file manager. The remaining file loads straight back
   into MLabel as input, so you can stop and pick up later, or hand the rest to someone
   else. No remaining file is written when all records are complete.

   **Partially entered answers are not saved in the remaining file.** A successful export
   clears the saved session. To pause while keeping those answers, close the app and
   [resume the same session](/guide/sessions/) before exporting.

</Steps>
