# Changelog

## 0.4.0

- Added Settings with shortcut rebinding, version information, a readable config summary, saved-session details, and update preferences.
- Added an in-memory network activity log for update requests.
- Unified keyboard shortcuts across the toolbar, help dialog, and field controls. Personal bindings persist across launches.
- Added controls for jumping to unfinished records, with feedback when there are no more in that direction.
- Expanded display rules with text, numeric, cross-field, and list comparisons, card notes, and per-item highlights.
- Improved input parsing for common date formats and delimited lists. Dates are interpreted and displayed in UTC.
- Made unreadable source values easier to identify without interrupting labeling.
- Enabled update checks in development builds, with manual download links where in-place installation is unavailable.
- Added configuration validation tooling and expanded the documentation and schema reference.
